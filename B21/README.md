# B21 — Design and Implement a Cybersecurity Learning Activity

## Activity Overview
A cybersecurity learning activity was designed and implemented using Google Forms titled:

**“Cybersecurity Awareness Activity: Spot the Phishing Attack”**

The activity focused on improving awareness of:
- Phishing attacks  
- Unsafe websites  
- Weak password practices  
- Common cybersecurity risks  

## Implementation
The activity used scenario-based quiz questions simulating real-world situations, including:
- Suspicious emails  
- Fake domains and websites  
- Urgent scam messages  
- Unsafe security practices  

Each question provided immediate feedback explaining the correct answer and the associated cybersecurity concept.

## Findings
- Participants could identify obvious phishing signs such as urgency and suspicious links  
- Realistic-looking fake domains were more difficult for users to detect  
- Many users relied heavily on visual trust cues and branding  
- Interactive learning improved engagement and understanding more effectively than passive reading  

## Key Insights
- Users often fail to verify URLs and technical indicators carefully  
- Familiar branding can increase user trust even in malicious scenarios  
- Continuous cybersecurity awareness training is important for reducing human-related risks  
- Scenario-based learning helps reinforce practical cybersecurity decision-making  

## Evaluation
The activity successfully demonstrated that interactive quizzes can improve cybersecurity awareness and encourage safer online behavior.
