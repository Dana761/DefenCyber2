# B26 – Help Another Student Understand a Cybersecurity Concept

## Objective
Help another student understand the concept of an Application Intrusion Detection System (AppIDS).

## Activity Description
I assisted another student, Kent Leonardi (24296478), through an online discussion about how AppIDS works and how it differs from a firewall.

## Discussion Summary
The student initially misunderstood AppIDS as being similar to a firewall.

I explained that:
- A firewall protects at the network level by filtering traffic.
- AppIDS operates at the application level by monitoring internal application behaviour.

Examples discussed included:
- SQL injection attempts
- Unauthorized access to restricted functions
- Abnormal user activity inside an application

The explanation helped clarify that AppIDS focuses on detecting suspicious behaviour within the application rather than simply blocking network traffic.

## Findings
- The student successfully understood the difference between firewalls and AppIDS.
- The student was able to summarize how AppIDS monitors user interactions and detects attacks that traditional network security tools may miss.
- The activity reinforced cybersecurity knowledge through peer-to-peer learning and practical explanation.

## Conclusion
This activity demonstrates the importance of communication and collaboration in cybersecurity education. Explaining concepts to others helps improve both technical understanding and critical thinking skills.
