# B15 — Teach an Elderly Person About Cybersecurity

## Activity Overview
For this activity, I taught my elderly neighbour, Pak Supriadi, about cybersecurity awareness through a WhatsApp conversation. The discussion focused on password security and safe password practices.

## Topic Chosen
Password Security and Strong Password Practices

## Conversation Summary
The discussion covered:
- Risks of using the same password across multiple accounts  
- How stolen passwords can be reused by attackers  
- Characteristics of strong passwords  
- Avoiding personal information in passwords  
- Importance of keeping passwords private  
- Using password managers to store passwords securely  

Pak Supriadi responded positively and demonstrated understanding of the advice provided.

## Cybersecurity Concepts Discussed
- Password reuse risks  
- Account compromise  
- Strong password creation  
- Password confidentiality  
- Password managers  
- Basic account protection practices  

## Findings / Reflection
- Many elderly users prefer weak or repeated passwords because they are easier to remember  
- Simple explanations and practical examples improved understanding  
- Pak Supriadi understood the importance of using different and stronger passwords  
- The activity improved my ability to explain cybersecurity concepts to non-technical users
