# B2 — Strong Security Implementations

## 1. Passkey-Based Authentication (WebAuthn)
- **Platform:** Google Account Login  

### Description
Google uses passkey-based authentication with WebAuthn, allowing users to log in using biometrics or device PINs instead of passwords.

### Security Features
- Passwordless authentication  
- Device-bound private key  
- Biometric/PIN verification  
- Phishing-resistant login system  

### Impact
Reduces:
- Phishing attacks  
- Credential theft  
- Password reuse vulnerabilities  

### Why It Is Strong
The private key never leaves the user’s device, making credential theft significantly harder.

## 2. Multi-Step Authentication with CAPTCHA and Email OTP
- **Platform:** PUBG Mobile  

### Description
PUBG Mobile requires CAPTCHA verification before sending a one-time password (OTP) to the user’s email.

### Security Features
- CAPTCHA protection  
- Email OTP verification  
- Time-limited authentication code  
- Multi-step verification  

### Impact
Reduces:
- Automated login attempts  
- Credential stuffing attacks  
- Unauthorized account access  

### Why It Is Strong
Combines human verification and identity verification in multiple authentication stages.

## 3. Anti-Phishing Website Verification System
- **Platform:** PUBG Mobile  

### Description
PUBG provides an official verification tool to help users identify legitimate PUBG-related websites.

### Security Features

- Anti-phishing guidance  
- Official source validation  

### Impact
Reduces:

## 4. Real-Time Anti-Cheat Detection System
- **Platform:** PUBG Mobile (Ban Pan Security System 3.0)  

### Description
PUBG monitors player behavior in real time and automatically detects and removes cheaters.

### Security Features
- Real-time monitoring  
- Automated cheat detection  
- Immediate enforcement system  

### Impact
Reduces:
- Cheating activities  
- Exploitation of game systems  
- Platform abuse  

### Why It Is Strong
Acts proactively by detecting malicious behavior while the activity is happening.

---

## 5. Ride Verification PIN System
- **Platform:** Uber  

### Description
Uber generates a unique PIN for every trip to verify both passenger and driver identities before the ride begins.

### Security Features
- Unique trip verification code  
- Mutual identity verification  
- Impersonation protection  

### Impact
Reduces:
- Entering the wrong vehicle  
- Passenger/driver impersonation  
- Physical safety risks  

### Why It Is Strong
Extends cybersecurity principles into real-world physical safety verification.
