# B27 – Apply a Learned Cybersecurity Concept to a Real-World Application

## Concept Applied
Access Control and Principle of Least Privilege

## Real-World Application
The concept was applied to Microsoft OneDrive using a University of Western Australia student account.

## Findings
A folder titled “UWA Essential Document” was analysed using the Manage Access feature.

Observations:
- Only the owner had access to the folder.
- No public links or additional users were granted permissions.
- The folder was private by default.
- Sharing controls allowed permissions to be added only when required.

This demonstrates that the system restricts access unless explicitly granted by the owner.

## Impact
- Prevents unauthorized access to sensitive files
- Reduces accidental data exposure
- Maintains user control over file permissions
- Supports secure collaboration through controlled sharing

## Application of Concept
The system demonstrates the principle of least privilege by limiting access only to authorized users. Proper authentication and authorization mechanisms ensure that resources are protected from unauthorized access.

## Recommendations
- Keep sensitive folders private by default
- Only share files with trusted users
- Avoid public sharing links when unnecessary
- Regularly review and remove unused permissions

## Conclusion
This activity demonstrates how access control and least privilege principles are implemented in real-world cloud storage platforms to improve data security and protect sensitive information.
